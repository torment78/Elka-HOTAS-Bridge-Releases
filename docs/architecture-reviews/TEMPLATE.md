## Executive Summary

State the decision requested, outcome, and release or activation impact.

## Evidence

List reproducible builds, tests, validator reports, measurements, compatibility data, and manual records. Mark unavailable evidence explicitly.

## Performance

Review latency, throughput, queues, CPU, memory, allocation, UI sampling, and soak evidence relevant to the scope.

## Maintainability

Review ownership, coupling, dependency direction, testability, failure isolation, and technical debt.

## Public APIs

Review contract versions, compatibility, documentation, negotiation, deprecation, and migration.

## Plugin Interfaces

Review lifecycle, isolation, permissions, failures, diagnostics, and compatibility even when the scope does not add a plugin.

## Runtime Diagnostics

Review telemetry, stage metadata, errors, health, recovery, and support-report evidence.

## Backward Compatibility

Review profiles, settings, workspaces, recordings, packages, scripts, plugins, migrations, backups, rollback, and existing hardware behavior.

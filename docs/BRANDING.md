# Elka HOTAS Bridge Branding

## Product name

The official user-facing product name is:

**Elka HOTAS Bridge**

`HOTAS` is always written in uppercase.

## Compatibility identifiers

The following established identifiers remain `HOTASBridge` so upgrades and existing user data continue to work:

- .NET namespaces and project names
- `HOTASBridge.App.exe`
- Visual Studio solution and project filenames
- `%LOCALAPPDATA%\HOTASBridge`
- profile and package filename extensions
- installer AppId and default installation directory
- existing signed release filenames and tags

These internal identifiers are implementation details and do not change the visible product name.

The palette intentionally follows the application theme:

- deep charcoal-green background
- dark green-teal panels
- muted teal and green signals
- restrained amber accent

Bright magenta, pink, purple, neon, glow, and gradient treatments are not part of the product palette.
